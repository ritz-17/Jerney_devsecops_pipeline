🚀 Jerney DevSecOps Pipeline (Beginner Project)

This project is based on Jerney, which is an open-source blog platform.
I did not build the application itself — I worked on the DevSecOps pipeline implementation for learning purposes.

📌 About the Project

Jerney is a blog platform where users can:

Create posts
Edit posts
Delete posts
Comment on posts

My contribution focuses on setting up the deployment and DevSecOps pipeline for this application.

🛠️ Tech Stack

Application (Open Source):

React (Frontend)
Node.js + Express (Backend)
PostgreSQL (Database)

My Work (DevSecOps):

Docker (Containerization)
Kubernetes (EKS)
Terraform (Infrastructure as Code)
GitHub Actions (CI/CD Pipeline)
Basic security scanning (SAST/DAST concepts)
⚙️ What I Implemented
Created Docker setup for the application
Wrote Terraform scripts to provision infrastructure
Deployed the app on Kubernetes (EKS)
Built CI/CD pipeline using GitHub Actions
Integrated basic security checks in the pipeline
🔄 Pipeline Flow (Simple)
Code is pushed to GitHub
GitHub Actions pipeline runs
Application is built
Docker image is created
Image is deployed to Kubernetes
Application goes live

How DevOps pipelines work in real projects
Basics of DevSecOps practices
Infrastructure automation using Terraform
Containerization and orchestration
Importance of security in CI/CD
